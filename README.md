# Cort1so1

Интерактивный симулятор системной утилиты для демонстрации визуальных процессов в среде iOS 26 с использованием исключительно нативных системных компонентов Apple. Приложение написано на языке Swift с использованием фреймворка SwiftUI.

---

## Архитектура и функциональные возможности

### 1. Навигация и системные элементы
- Использование стандартного системного компонента TabView со встроенным эффектом системного размытия фона (.ultraThinMaterial).
- Использование строго стандартных элементов управления Apple: системные списки List и Form, нативные переключатели Toggle, сегментированные селекторы Picker (.pickerStyle(.segmented)), системные кнопки Button (.buttonStyle(.borderedProminent)) и индикаторы ProgressView.
- Поддержка двух режимов отображения:
  - Светлая тема: стандартный светлый системный фон, системные элементы и темный текст.
  - Темная тема: стандартный темный системный фон, системные элементы и светлый текст.
- Управление темой осуществляется через нативный Toggle в разделе «Настройки» с сохранением состояния в AppStorage и применением модификатора preferredColorScheme.

### 2. Вкладка «Основное» (Пайплайн симуляции)
- Системный сегментированный переключатель режимов выполнения (Стандартный / Rootless / Разработчик).
- Нативная информационная панель с данными о состоянии системы (iOS 26.0, arm64e, статус «Совместимо»).
- Нативная кнопка запуска «Jailbreak» со стандартным стилем .borderedProminent.
- Фаза 1 (Инициализация): последовательная пошаговая анимация с системным ProgressView («Инициализация среды», «Поиск смещений ядра», «Обход защитных механизмов», «Получение привилегий tfp0», «Подготовка Bootstrap»).
- Фаза 2 (Быстрый лог): полноэкранный терминал со скоростным выводом системных сообщений моноширинным шрифтом сверхмелкого размера (.font(.system(size: 7, design: .monospaced))) и автопрокруткой.
- Фаза 3 (Респринг): оверлей симуляции перезапуска интерфейса SpringBoard (NeoSpringView) с центрированным индикатором ProgressView на черном фоне.

### 3. Вкладка «Откат iOS»
- Системный список и меню выбора версии прошивки (iOS 26.0, iOS 25.5.1, iOS 25.4, iOS 25.1, iOS 18.0).
- Отображение сведений о сборке, дате выхода, размере файла и статусе цифровой подписи Apple (TSS / SHSH2).
- Симуляция процесса загрузки, распаковки разделов SEP/Baseband и проверки контрольных сумм SHA-256 через нативный ProgressView.

### 4. Вкладка «Настройки»
- Нативный системный Form с секциями.
- Переключатель тем оформления.
- Параметры работы симулятора (подробный вывод логов, автоматический респринг, инъекция твиков).
- Системные сведения и информация о версии утилиты.

## Автоматическая сборка в GitHub Releases

В репозитории настроен автоматический рабочий процесс GitHub Actions (.github/workflows/build.yml).

При отправке коммита в ветку main или создании тега:
1. Запускается виртуальная машина macOS (macOS-14).
2. Выполняется компиляция проекта через xcodebuild в конфигурации Release.
3. Собранный пакет Cort1so1.app упаковывается в Cort1so1.ipa.
4. Создается автоматический релиз в разделе Releases репозитория с прикрепленным готовым файлом Cort1so1.ipa.

## Установка приложения

1. Перейдите во вкладку Releases вашего GitHub-репозитория.
2. Скачайте файл Cort1so1.ipa из блока Assets.
3. Установите IPA на устройство с помощью одной из утилит:
   - TrollStore (для поддерживаемых версий iOS с перманентной подписью)
   - AltStore / SideStore
   - Sideloadly
